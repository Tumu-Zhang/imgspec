# 打赏收款码（维护者说明）

README 底部的「请作者喝杯咖啡」区块读取本目录下的两张图片：

```
docs/donate/wechat.png   微信收款码（建议 500×500 以上正方形）
docs/donate/alipay.png   支付宝收款码
```

启用步骤：

1. 把两张收款码图片放到本目录，命名为 `wechat.png` 和 `alipay.png`
2. 打开 `README.md`，搜索 `DONATE-BEGIN`，删掉包裹打赏区块的
   `<!-- DONATE-BEGIN -->` 和 `<!-- DONATE-END -->` 两行注释
3. 提交推送即可生效

收款码里的个人隐私信息（昵称、头像）会公开，介意的话可以使用
「赞赏码」或新建一个用于收款的昵称。
