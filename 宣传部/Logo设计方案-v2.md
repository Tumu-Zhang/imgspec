## 1. 品牌内核

**一句话定位**：把「原始素材」变成「期刊能收的图」——固定 DPI、固定物理尺寸、固定格式，批量、可复现、零 AI 重绘。

**品牌性格**：专业、精确、可信、干净。用户是科研工作者，Logo 应像一把「卡尺」，而不是一支「画笔」。

**设计约束**（来自现状）：

- 皇家蓝（#2563eb / #1e40af）已深度绑定界面 accent 色，是必须保留的品牌资产；
- 品牌青（#22d3ee）作为点睛色，与蓝色形成「蓝 = 输入/主体，青 = 动作/转换」的语义分工；
- 图标由 `theme.icon_pixmap()` 用 QPainter 代码自绘（非位图），方案必须能用基础几何图形（圆角矩形、多边形、圆、线段）表达；
- 16px 任务栏图标必须可辨识，因此每个方案都带「小尺寸减法版」。

## 2. 三个候选方案

### 方案 A · 传承进化（推荐）

- **图形概念**：保留现行「白色相片卡（山与太阳）+ 右下青色拖角箭头」的图形 DNA，做几何化精修——统一圆角（与界面 12px 卡片语言一致）、加粗箭头笔画、相片卡略上移为箭头让出视觉动线。
- **设计逻辑**：相片卡 = 输入图片；拖角箭头 = 「拉到目标规格」。图标讲的就是软件做的事，用户认知零成本，风险最低。
- **适用场景**：全场景通用，尤其适合不希望老用户感到「换了个软件」的平稳迭代。

### 方案 B · 规格框

- **图形概念**：一只带工程尺寸标注线的图框——白色线框内是简化的「山」，顶部与左侧是青色尺寸标注线（端点刻度），四角是青色控制点（选中态手柄）。
- **设计逻辑**：直接把「规格」二字画出来。尺寸标注线是工程图/期刊排版要求（8.5 cm、300 dpi）的视觉语言，学术气质最强，与泛用图片工具（滤镜、美图类）区分度最高。
- **适用场景**：强调「科研投稿工具」定位、面向期刊投稿人群做传播时最有说服力。

### 方案 C · 像素归位

- **图形概念**：左侧散乱漂浮的像素方块，经一道青色转换箭头，归位为右侧严整的 3×3 网格（中心一格青色，是「被规格化的那一个」）。
- **设计逻辑**：讲「过程」——转换就是归位。最抽象、最现代，不依赖「相片」隐喻（软件同样处理 PPT/PDF 矢量稿，像素叙事反而更包容）。16px 收敛为 2×2 像素章，是小尺寸辨识度最好的方案。
- **适用场景**：适合做品牌升级叙事，且天然支持动效延伸（启动画面像素归位动画）。

## 4. 字体建议（字标组合用）

- **中文字标**：思源黑体 / 阿里巴巴普惠体 Bold——开源可商用，与界面字体栈（Microsoft YaHei UI / PingFang SC）气质一致；
- **英文 IMGSPEC**：Inter / Manrope SemiBold，全大写 + 加宽字距（letter-spacing ≈ 0.3em），传达「规格、精确」；
- 应用内标题维持现有 UI 字体栈不变，字标仅用于 README、发布页、关于对话框等对外触点。

## 5. VI 应用规范（落地后生效）

1. **图标组合**：主标记（方底图标）/ 横排组合（图标 + 图片转换器 + IMGSPEC）/ 单字标（仅社交头像等方形容器）；
2. **最小尺寸**：应用图标 16px 用减法版；印刷不小于 8mm；
3. **安全区**：图标边长的 1/4（拖角箭头可伸入安全区，属品牌特征）;
4. **背景规则**：优先白 / 浅灰底；深色底上使用同一枚标记（底板自带蓝色，无需反白版）；
5. **不要**：改品牌色、拉伸变形、加描边/阴影、旋转。
